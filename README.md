# 🦊 Pake Vibe Coding

Proyek boilerplate modern menggunakan **Bun**, **Elysia**, dan **Drizzle ORM** dengan database **MySQL**. Dibuat dengan estetika tinggi dan performa maksimal.

## 🚀 Fitur Utama

- **Bun Runtime**: JavaScript runtime super cepat.
- **ElysiaJS**: Web framework ergonomis untuk Bun.
- **Drizzle ORM**: TypeScript ORM yang ringan dan type-safe.
- **MySQL**: Database relasional yang handal.

## 🛠️ Tech Stack

- **Runtime**: [Bun](https://bun.sh)
- **Framework**: [Elysia](https://elysiajs.com)
- **Database**: MySQL
- **ORM**: [Drizzle](https://orm.drizzle.team)

## 📦 Instalasi

```bash
bun install
```

## 🏃 Menjalankan Aplikasi

Mode Development:
```bash
bun run dev
```

Mode Produksi:
```bash
bun run index.ts
```

## 🛣️ API Endpoints

- `GET /` : Health check & welcome message.
- `GET /users` : Mengambil daftar semua user dari database.
